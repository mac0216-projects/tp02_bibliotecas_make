# tp02_bibliotecas_make
O objetivo deste trabalho é projetar, implementar, testar e documentar uma biblioteca reutilizável em linguagem C. O projeto deverá ser organizado em módulos, disponibilizar uma interface pública, ser compilável automaticamente com Make, gerar bibliotecas estática e dinâmica, possuir testes automatizados e utilizar Git para registrar sua evolução.
